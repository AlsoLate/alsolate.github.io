# Minecraft 客户端时间线

记录 Minecraft 客户端发展历程的公开时间线，从 2010 年的 Zombe's Modpack 一直排到今天，目前收录 72 个客户端。

**在线地址：<https://cheatcracker.github.io/>**

## 功能

- **三种视图**：图谱（按时间铺开的时间轴）、横向、纵向。窄屏默认纵向，宽屏默认图谱
- **四套主题**：极简（默认）、午夜蓝、赛博朋克、复古，选择记在本地，详情页会沿用
- **详情页**：每个客户端独立页面，记录开发者、平台、基于哪个客户端魔改、适配的反作弊、获取方式与现状
- **反作弊标注**：区分 NCP 与 Grim 两个时代，卡片上直接可见
- **排序**：最新 → 最早（默认）/ 最早 → 最新，图谱视图下会翻转整条时间轴

## 数据

全部内容都在 `timeline.json` 一个文件里。

| 字段 | 说明 |
| --- | --- |
| `id` | 唯一标识，详情页地址为 `client.html?id=<id>` |
| `name` | 客户端名称 |
| `description` | 一句话简介，卡片与列表用 |
| `story` | 详细介绍，详情页优先使用；没有时退回 `description` |
| `year` / `month` | 时间。`month` 可省略，省略时只显示年份，不编造月份 |
| `anticheat` | 适配的反作弊：`NCP` / `Grim` / `NCP → Grim` / `通用` |
| `base` | 基于哪个客户端魔改 |
| `developer` / `platform` / `license` / `status` | 开发者 / 平台 / 获取方式 / 现状 |
| `features` | 特性标签数组 |
| `aliases` | 别名数组 |
| `color` | 标题颜色 |

新增一个客户端，只要往数组里加一个对象，首页和详情页都会自动生成。查不到的字段留空即可，页面上不会显示空行。

## 本地预览

页面通过 `fetch` 读取 `timeline.json`，直接双击打开 `index.html` 会被浏览器的 CORS 策略拦住，需要起一个本地服务器：

```bash
python -m http.server 8000
```

然后访问 <http://127.0.0.1:8000/>。

## 关于资料

早期客户端的信息主要来自 2b2t Wiki、各客户端官网与 GitHub；2025–2026 年的中文客户端来自 2b2t.xin 论坛与 3C3U Wiki。

**查不到的字段一律留空，不做推测。** 反作弊标注按客户端活跃期划分：

- **2b2t.org** — 自 1.19 起为 GrimAC，此前为 NCP
- **2b2t.xin** — NCP魔改版
- **3c3u.org** — 自 2024.5 起为 GrimAC v3 魔改版，此前为 NCP
